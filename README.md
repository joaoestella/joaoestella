## Projects

### AI Engineering

**Face Analysis App** *(launching soon)*  
Personalized facial visualization app. React, TypeScript and Vite front-end, with a custom RTMPose-based pose estimation model trained on a hand-annotated dataset, reaching 93% accuracy.

**[rag-pdf-project](https://github.com/joaoestella/rag-pdf-project)**  
Local RAG pipeline for document Q&A, built with LangChain, Ollama, and ChromaDB, with a Streamlit interface. Tested on a 216-page technical document, with tuning on chunking, MMR retrieval, and multi-query for better answer accuracy.

### Data

**[Tennis-Analysis](https://github.com/joaoestella/Tennis-Analysis)**  
Statistical and predictive analysis of ATP tennis matches. Includes a logistic regression model for match outcomes, era dominance analysis, ranking correlation, and upset/betting ROI analysis.

**[IA-Course-Projects](https://github.com/joaoestella/IA-Course-Projects)**  
Collection of data science and applied ML projects from the AI Engineering track (2025).

### Academic Projects

**FESTO (2025)**  
Digital Twin of a pneumatic system. Collected sensor data via a PLC provided by Festo, processed it, and built a predictive model plus a real-time monitoring dashboard.

**SPI (2024)**  
Robotic system with computer vision for object classification and manipulation. Built a custom image dataset and trained a YOLO-based detection model, integrated with the robotic arm's control.

**Raízen (2023)**  
Mobile app built with App Inventor, connecting via Bluetooth to an OBD2 module for real-time vehicle data display.
